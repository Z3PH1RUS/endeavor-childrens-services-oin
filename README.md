# Endeavor Children's Services — OIN-Inspired Layout (Variant C)

Design variant C for comparing Endeavor website redesign options. Layout inspired by [Orphans in Need USA](https://oinusa.org/) — patterns only, no OIN assets or copy.

## Stack

- Next.js App Router + TypeScript + Tailwind CSS 4
- Static export (`output: 'export'`, `images.unoptimized`)
- GitHub Pages base path: `/endeavor-childrens-services-oin`

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Output goes to `out/`.
