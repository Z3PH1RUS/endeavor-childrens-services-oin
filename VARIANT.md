## Variant A — Teal Nonprofit Redesign

**Repo:** `Z3PH1RUS/endeavor-childrens-services`  
**Inspiration:** Sheltering Arms layout patterns (warm nonprofit polish)

| Dimension | Variant A (Teal) | Variant C (OIN) |
|-----------|------------------|-----------------|
| **Color palette** | Endeavor brand teal (`#1a9aaa`) + gold accent on dark slate footer | Deep forest green (`#1a5c3e`) + amber/gold CTA (`#e8a317`) on warm cream backgrounds |
| **Typography** | Source Serif 4 (headings) + DM Sans (body) — serif/sans pairing | Poppins (bold headings) + Open Sans (body) — all sans-serif, heavier weights |
| **Hero** | Full-width gradient teal band with decorative circles, quote as blockquote | Split layout: mission copy left, Quick Donate card right on warm cream background |
| **Donation UX** | Donate button in nav; donation details on Get Involved page | Donation-first: Quick Donate widget in hero, dual CTAs on program cards (Donate Now + Learn More) |
| **Program presentation** | Icon-based cards with emoji, hover lift | "Appeal" cards with gradient image bands, OIN-style Donate/Learn More button pairs |
| **Impact stats** | Dark slate full-width band, gold numbers | White bordered stat cards in a grid on light background |
| **Stories** | Not on homepage | "Stories of Impact" quote grid from real I Am Who? participant words |
| **Header** | Sticky white header with backdrop blur | Dark green utility top bar (phone, Facebook) + white header with amber Donate Now |
| **Section rhythm** | Alternating white / light gray | White / warm cream (`#faf8f5`) with green accent bands |
| **Footer** | Dark teal-slate, gold-accent column headers | Dark forest green, amber uppercase column labels |
| **Overall feel** | Editorial, dignified, brand-continuity with original WordPress teal | Action-oriented humanitarian charity, donation-conversion focused |

## What Variant C Borrows from OIN (Patterns Only)

- Utility top bar with contact shortcuts
- Quick Donation card in the hero area
- Program sections styled as "appeals" with paired Donate/Learn More actions
- Large-number impact statistics section
- Stories/testimonials grid
- Get Involved callout band
- Tax-deductibility note near donation CTA
- Bold sans-serif heading hierarchy
- Amber/gold primary action buttons on green brand base

## What Variant C Does NOT Copy

- OIN name, logo, photos, or copy
- OIN-specific programs (Zakat, orphan sponsorship tiers, etc.)
- OIN color values exactly — palette is adapted for Endeavor
- Any fabricated Endeavor content — all text from the research crawl
